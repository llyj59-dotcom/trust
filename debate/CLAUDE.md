# 생각 모으기 (토의·토론 웹앱)

이 폴더(`debate/`)만 이 앱입니다. 같은 저장소의 루트 `index.html`과 `Jua-OFL.txt`는 「신뢰를 사다」 게임이므로 건드리지 않습니다.

- 배포 주소: https://llyj59-dotcom.github.io/trust/debate/ (GitHub Pages, main 브랜치)
- 구조: `index.html` 한 파일에 CSS, 데이터, JS가 모두 들어 있습니다. 서버·로그인 없음, 외부 전송 없음.
- 사용자: 초등 6학년 담임 선생님과 학급 아이들(크롬북·태블릿). 패들렛 유료 사용. 글쓰기 AI 피드백 사이트 '자작자작'(무료 이용)이 따로 있음.
- 말투 지침: 단정적이고 강한 말보다, 사람이 말하듯 부드럽고 자연스럽게.

## 학생 흐름 7단계
주제 고르기 → 처음 내 자리 → 주장·이유·근거·영향 → 스스로 다듬기 → 반대편에서 가장 센 말 → 발표 카드·복사 → 나를 움직인 말·나중 자리

## 설계 이유 (바꾸기 전에 읽기)
- 찬반 대신 0~10 가치 수직선: 편 가르기를 피하고 "나는 7인데 너는 왜 9야?"라는 대화를 만들기 위해서입니다.
- 처음·나중 자리를 둘 다 받습니다. "옮긴 사람 수"가 이 앱의 핵심 숫자입니다. 이긴 사람이 아니라 생각이 움직인 사람을 칭찬하게 하려는 장치입니다.
- 스스로 다듬기의 노란 칸이 있어도 다음으로 넘어갈 수 있어야 합니다. 막으면 아이가 포기합니다.
- 반대편의 '가장 센 말'을 먼저 고르게 합니다. 약한 반론을 고르면 자기 생각도 약해지기 때문입니다.
- 결론 짓기는 다수결이 아니라 단계: 다시 서 보기 → 공통 기반 → 쟁점 좁히기 → 조건 붙이기(핵심) → 합의문(동의한 것/갈리는 것/하기로 한 것/더 알아볼 것). 표결은 마지막 수단이고 '오늘의 잠정 결론'으로 부르며 소수 의견을 합의문에 적습니다.

## 건드릴 때 주의
- 결과 코드 한 줄 `@@이름|주제id|처음|나중|근거종류|점검@@` (resultText, parsePastes). 칸 순서를 바꾸면 아이들이 이미 복사해 둔 결과를 읽지 못합니다. 늘릴 때는 뒤에만 붙입니다.
- 주제를 추가하면 `TOPICS`와 함께 `ENDS`(수직선 양 끝 문구)도 반드시 넣습니다. 빠지면 '아니다/그렇다'로 어색하게 나옵니다.
- `localStorage` 키 `saenggak-moagi-v1`을 바꾸면 쓰던 기록이 사라집니다.
- 안 되는 것: 실시간 공유(서버 없음), 교사가 붙여넣은 내용 저장(새로고침하면 사라짐), 모둠 집계.
